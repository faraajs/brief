# Security policy

Only the latest published release receives security fixes.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/faraajs/brief/security/advisories/new), not a public issue. Include the app version, Android version, device ABI, affected behavior, and a minimal reproduction using synthetic audio or video. Do not post private recordings, credentials, personal paths, or unredacted device logs.

Reports are reviewed by the maintainer. No response-time guarantee or claim of complete security coverage is made.
